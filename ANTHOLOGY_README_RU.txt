Anthology на IX-Ray — экспериментальная ветка, 09.10.2026

Ветка anthology-ixray-experimental содержит самостоятельный порт на IX-Ray.
Основной Anomaly/Monolith v170 находится в отдельной ветке anthology-v170-terrain-pom.
Эти ветки имеют разные базы движка; их нельзя объединять обычным merge для обновления игры.
Upstream IX-Ray: 612b165c97d5e6a50ac0a6d1384ac8c95a63dda5.

Содержимое:
  src/ — нативный движок с переносом API и загрузчиков Anomaly;
  anthology-compat/gamedata/ — 32 файла адаптации Anthology/MO2;
  tools/tests/ — проверки C++/Lua и переносимый скрипт их запуска;
  gamedata/ — штатные шейдеры, шрифты и ресурсы IX-Ray.
Объёмные ресурсы самой Anthology и сторонние моды в этот репозиторий не включены.

Последние исправления:
  - атласы и метрики шрифтов Anomaly, CP1251/UTF-8, переопределение текстур UI;
  - вызовы скриптового инвентаря, слоты/рюкзак, элементы и подсказки MCM;
  - настоящий API опускания оружия, hud_adjust для Weapon Cover Tilt, стрельба;
  - XML с авторскими комментариями перед декларацией загружается как в Anomaly;
    это исправляет загрузку HUD-маркеров и части переводов MCM;
  - неудачная повторная загрузка XML не оставляет указатели на прежние узлы.

Сборка (Windows, Visual Studio 2022 / MSVC v143, CMake, Windows SDK):
  cmake -S . -B build-x64 -G "Visual Studio 17 2022" -A x64 -DIXRAY_USE_R1=OFF -DIXRAY_USE_R2=OFF -DIXRAY_USE_COMPRESSOR=OFF -DIXRAY_MP=OFF -DIXRAY_EDITORS=OFF -DIXRAY_UTILS=OFF -DIXRAY_PLUGINS=OFF -DIXRAY_DISCORD_RPC=OFF -DANTHOLOGY_LUA_API_CHECKS=ON -DANTHOLOGY_COMPAT_TESTS=ON
  cmake --build build-x64 --config RelWithDebInfo --parallel 2
  py -3 tools/tests/run_anthology_checks.py
Проверки принимают --bin-dir, если путь к собранным DLL/EXE отличается.
Зависимости CMake берёт из указанных в репозитории источников; нужен доступ к ним.

Сборка мода совместимости для отдельной копии игры:
  - исходное содержимое gamedata/shaders, gamedata/fonts и gamedata/scripts/ixray_system;
  - gamedata_coc/configs/ui/backend, engine_external.ltx, ui_mm_loading_screen.xml,
    ui_mm_loading_screen_16.xml и textures_descr/ui_mm_loading_screen.xml;
  - поверх них содержимое anthology-compat/gamedata.
В fsgame добавить $game_fonts$ = true | false | $game_data$ | fonts\
EXE/DLL из build-x64/bin/RelWithDebInfo размещаются в отдельной папке движка.
В MO2 использовать отдельный профиль, мод совместимости с последним приоритетом,
рабочий каталог игры и отдельный appdata. Обычный запуск не требует диагностических флагов.
Скрипты zz_anthology_ixray_*_probe активны только с явными флагами диагностики.

Ограничения:
  - старые сохранения Anomaly с LuaJIT bytecode v1 несовместимы с LuaJIT IX-Ray;
    для теста нужна новая игра и её собственные сохранения;
  - PiP/FakeLens, DLSS/FSR, сезоны/шейдерный снег ещё не перенесены полностью;
  - ScriptAttachment, GFY HUD экзоскелета, часть WD/freelook/источников света,
    HUD-капли/автоматический gloss SSS, EFX SAR и R1/Echo DLL требуют дальнейшего переноса;
  - уже существовавшие ограничения описаны явно; наличие раздела MCM не означает,
    что соответствующая функция рендера Anomaly реализована в IX-Ray;
  - торговля, ремонт, квестовые цепочки и переходы между локациями не прошли полный QA;
  - визуальные позы Cover Tilt ещё требуют сравнения с Anomaly;
  - преимуществ по FPS пока не подтверждали сопоставимым измерением;
  - в ранних прогонах были нестабильные native/heap/XML-сбои. Их причины полностью
    не установлены; успешные последние прогоны не доказывают устранение всех;
  - остаются отдельные ошибки исходных XML st_anthology_sms и st_quests_general_sp.

Совместимость параметров включена DLTX EnableAnomalyParams=true. Штатные параметры
IX-Ray остаются доступны; для поддержанных параметров предметов предусмотрен
anomaly_params=false. MCM IX-Ray управляет 23 реальными командами движка.
Лицензии upstream и авторство сторонних скриптов сохраняются в исходных файлах.
