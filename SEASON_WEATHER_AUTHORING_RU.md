# Календарь и собственная сезонная погода

Календарь использует месяц игровой даты из сохранения. Соответствие месяцев и шести существующих пресетов задаётся в `gamedata/configs/anthology_seasons.ltx`. В MCM календарь можно отключить и оставить ручной выбор. Переход между пресетами происходит при смене месяца, без ежедневного смешивания DDS.

Чтобы добавить свою погоду:

1. Создать обычный цикл XRay в `gamedata/configs/environment/weathers/my_winter_clear.ltx`, включая необходимые времена суток, текстуры неба и другие ресурсы.
2. Создать собственный файл `gamedata/configs/anthology_seasons/my_weather_addon.ltx` с уникальными именами секций:

```ini
[weather_myaddon_winter_clear_01]
style = 4
category = clear
cycle = my_winter_clear
```

3. Перезапустить игру: список доступных циклов загружается при запуске.

`style`: 1 — лето, 2 — осень, 3 — голые деревья, 4 — зима, 5 — оттепель/поздняя осень, 6 — весна/исходные текстуры. Категории: `clear`, `partly`, `cloudy`, `rain`, `storm`, `foggy`. `cycle` — имя файла цикла без расширения.

Для каждого пресета и категории можно добавлять сколько угодно уникальных секций и циклов: отдельного численного лимита нет, действуют обычные ограничения памяти и ресурсов. Если сезонный пул для категории не задан, используется исходный пул модпака. Выбросы, подземелья, пауза погоды и переходы остаются под управлением исходного `level_weathers.WeatherManager`.

Для регистрации из Lua после загрузки погоды уровня:

```lua
local accepted = anthology_runtime_seasons.register_weather(4, "clear", "my_winter_clear")
```

Функция возвращает `false` при неверных аргументах или отсутствии загруженного цикла. Повторная регистрация не добавляет дубликат. Динамические регистрации следует повторять при запуске аддона; объекты движка в сохранениях не хранятся.

Пресет 4 включает адаптацию льда SSS и зимние свойства материалов `materials\water` / `materials\water_radiation`. Идентификаторы, пары материалов и радиационное воздействие сохраняются. При оттаивании возвращаются исходные свойства модпака. Геометрия озёр не создаётся заново: используется существующая коллизия уровня.

У снега добавлены ограниченные по стоимости проверки столкновений с близкими динамическими моделями. Накопления снега, следов и снега на HUD-оружии пока нет.
